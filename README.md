# Awesome iOS AI

Curated iOS on-device and Apple AI resources. Status is checked weekly.

## Core AI

- [apple/coreai-models](https://github.com/apple/coreai-models) - Apple's official Core AI export recipes and Swift runtime.
- [john-rocky/coreai-model-zoo](https://github.com/john-rocky/coreai-model-zoo) - Swift conversions of LLMs for Core AI.

## Core ML models

- [likedan/Awesome-CoreML-Models](https://github.com/likedan/Awesome-CoreML-Models) - Large collection of Core ML models. _(stale)_

## Curated lists

- [onmyway133/awesome-machine-learning](https://github.com/onmyway133/awesome-machine-learning) - Curated ML resources with a Core ML focus.

## Foundation Models

- [AppStorage/FoundationChat](https://github.com/AppStorage/FoundationChat) - SwiftUI chat app built on the Foundation Models framework (MIT). _(stale)_

## MLX

- [ml-explore/mlx-swift-lm](https://github.com/ml-explore/mlx-swift-lm) - Run and fine-tune LLMs and VLMs in Swift. iOS 17+. Includes MLXFoundationModels bridge for Apple's LanguageModelSession.
- [ml-explore/mlx-swift-examples](https://github.com/ml-explore/mlx-swift-examples) - Runnable iOS and macOS sample apps: MLXChatExample, LLMEval, StableDiffusionExample.
